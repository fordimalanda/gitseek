# GitSeek

Multi-repo dashboard with AI-assisted commits, powered by DeepSeek.

## Requirements
- PHP 8.4+
- Git installed and on PATH
- A GitHub Personal Access Token (scope: `repo`)

## Quick start
1. Copy `.env.example` to `.env` and fill in the values.
2. Run `scripts\dev.bat` (Windows) or `scripts/dev.sh` (Unix).
3. Open http://localhost:8000
